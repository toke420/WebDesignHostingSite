Tallyflow docs

Guides and API reference for the Tallyflow REST API (v1).

Getting started

Create your account, add your business details and send your first invoice in under five minutes.

curl https://api.tallyflow.example/v1/me \
  -H "Authorization: Bearer $TALLYFLOW_KEY"

Was this helpful?

Creating invoices

Invoices have line items, a due date and a client. Drafts can be edited until they are sent.

POST /v1/invoices
{
  "client_id": "cl_82hf",
  "due_in_days": 14,
  "items": [{ "description": "Design", "quantity": 10, "unit_price": 120 }]
}

Was this helpful?

Accepting payments

Turn on card and bank payments in Settings → Payments. Paid invoices are reconciled automatically.

GET /v1/invoices/inv_19a/payments

Was this helpful?

Automatic reminders

Reminders are sent 3 days before, on, and 7 days after the due date. You can customise the wording.

PATCH /v1/settings/reminders
{ "schedule": [-3, 0, 7] }

Was this helpful?

Webhooks

Receive an HTTPS POST when an invoice is paid, overdue or viewed. Verify the signature header.

{
  "type": "invoice.paid",
  "data": { "id": "inv_19a", "amount": 1320 }
}

Was this helpful?

API keys

Create keys in Settings → Developers. Keys can be scoped to read-only and revoked at any time.

export TALLYFLOW_KEY=tf_live_xxxxxxxx
